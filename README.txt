Installation
----------------------------------------------------------------
You will need the DOOM64.WAD from the Steam/Gamepass/GOG/Epic Games version of Doom 64 to make the Doom 64 ROM from the patch. Use one of these websites below to load the DOOM.WAD into the ROM slot and doom64xe.bps into the patch slot. Save the patched file with the .z64 extension and it should run on Nintendo 64 hardware (expansion pak required), MiSTer FPGA, and some emulators.

https://hack64.net/tools/patcher.php
https://www.marcrobledo.com/RomPatcher.js


Description
----------------------------------------------------------------
Doom 64 XE (eXpanded Edition) is a fork of Doom 64 with the goal of adding quality of life features, engine improvements, and bonus content while maintaining original demo compatibility. It is made possible due to the significant progress of the subsequent four projects.

Doom 64 Reverse Engineered: https://github.com/Erick194/DOOM64-RE/
Doom 64 Complete Edition: https://github.com/azamorapl/doom64-complete-edition
Doom 64 Modern Merciless Edition: https://github.com/jnmartin84/Doom-64-Merciless-Edition/
Doom 64 Ultra: https://github.com/thekovic/doom64ultra
Doom 64 Dreamcast: https://github.com/jnmartin84/doom64-dc/
