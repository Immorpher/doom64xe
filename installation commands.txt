LTO Stuff

Run the helper script from the repository root (needs git, python3 and the SDK installed above):

sudo ./build-libultra-lto.sh

It clones ModernN64SDK/libultra_modern, builds libultra_rom with -flto=auto -ffat-lto-objects,
and installs it over /usr/lib/n64/libultra_rom.a (original kept as libultra_rom.nolto.a).

Then build the ROM as usual:

cd doom64
./make-rom.sh

(make-rom.sh already puts /opt/crashsdk/bin in PATH, which is where the gcc LTO plugin wrappers live.)
